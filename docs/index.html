LILYGO T5 4.7 inch e-Paper に、ブラウザから直接ファームウェアを書き込みます。

バージョン %VERSION% ・ リリースノート

パソコンの Chrome または Edge で開いてください。 書き込みには Web Serial を使うため、iPhone や Android では動作しません。

手順

  1. 本体を USB-C でパソコンに繋ぐ
  2. ユーザーボタン（IO21）を一度押して本体を起こす
  3. 下のボタンを押す
  4. 表示されるダイアログでデバイスを選ぶ
スリープ中は書き込めません。 シリアルはチップ内蔵の USB-JTAG/CDC なので、ディープスリープに入るとデバイスの一覧から消えます。 画像を表示したまま 60 秒放置するとこの状態になります。ボタンを押して起こしてから開き直してください。

LILYGO T5 4.7 inch e-Paper（ESP32-S3）

4.7 インチ / 960 × 540 / 16 階調 ・ H716（タッチあり）と H578 / H580（タッチなし）で共通です

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。
ESP32 版（T5 4.7 の旧モデル）には書き込めません。 このファームウェアは ESP32-S3 版のみに対応しています。

基板の 3 つのボタン

ボタンGPIO役割
RST–リセット
BOOT0書き込みモード用。動作中は押さないでください
ユーザーボタン21このアプリが使うボタン。起こすときもこれ

BOOT (IO0) は e-paper の設定用シフトレジスタ（74HCT4094）の STR ラッチと共用です。 動作中に押すと表示が乱れることがあります。

使いかた

microSD のルートに jpeg か png を置いて電源を入れると、一覧から選んで全画面に表示できます。 画面に収まるよう自動で拡大・縮小し、EXIF の向きにも従います。

SD カードを抜き差ししなくても、スマホから画像を送れます。 本体の一覧から [WiFi] を選び、出てきた QR コードをカメラで読むだけです。 ブラウザだけで完結するので、アプリは要りません。SD カードが無くても表示できます。

うまくいかないとき

  • デバイスが一覧に出ない場合は、本体がスリープしています。ユーザーボタン（IO21）を押してから開き直してください。
  • それでも出ない場合は、BOOT を押したまま RST を押して離すとダウンロードモードに入ります。書き込み後は RST で再起動してください。
  • 書き込み後に一覧が空に見える場合は、SD カードに画像が入っているか確認してください。画面右上に no SD card と出ていれば、SD が読めていません。
